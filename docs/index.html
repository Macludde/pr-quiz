Prove you read the PR before you approve it.

Agent-written code gets merged unread. pr-quiz has your agent write 5–7 multiple-choice questions about the code itself. A skimmer gets them wrong; a reader gets them right.

Play the demo → Install

The demo quizzes honojs/hono#5351, which adds backpressure to the AWS Lambda streaming adapter. Two of its answers are consequences the PR description doesn't mention.

How it works

The agent reads the diff, every changed file and one hop of callers and callees, then writes quiz.json. A strict linter rejects lazy quizzes before anything is posted.

Six kinds of question

Each answer is a Mermaid diagram with the deciding step outlined, one or two sentences, and permalinks to the exact lines.

Where it runsREQUIRED

Which process runs this; what crosses which boundary?

ArchitectureREQUIRED

Who owns the behaviour, the call order, where state lives.

Design decisionREQUIRED

Why this over the obvious alternative; what forced it.

Behaviour

Given X while Y, what happens? Predicting forces reading.

Known issueREQUIRED

What is still unhandled; what breaks if an invariant fails.

Contract

Which invariant, test, flag or compatibility rule protects this.

6 · Known issue
A client disconnects from a streamSSE response and responseStream errors. What happens to the app's body stream?
  • A. pipeline cancels the body, so onAbort callbacks run as usual
  • B. Reads continue to the end, filling the dead stream's internal buffer
  • C. Reads stop, but the body is never cancelled, so onAbort never fires
  • D. The handler rejects, and Lambda retries the whole invocation
Answer

C. readWebStream has no finally that calls reader.cancel(), so the body's cancel hook, the only path to abort(), never runs.

Install

Needs Node 18+, git and an authenticated gh. Playwright is optional; it render-checks the diagrams.

git clone https://github.com/Macludde/pr-quiz ~/.claude/skills/pr-quiz
cd ~/.claude/skills/pr-quiz && npm i && npx playwright install chromium

Then, on a branch with an open PR: /pr-quiz, or ask “quiz me on PR 123”.

git clone https://github.com/Macludde/pr-quiz ~/.codex/skills/pr-quiz
cd ~/.codex/skills/pr-quiz && npm i && npx playwright install chromium

Then ask Codex to “use the pr-quiz skill on PR 123”.

git clone https://github.com/Macludde/pr-quiz ~/.agents/skills/pr-quiz
cd ~/.agents/skills/pr-quiz && npm i && npx playwright install chromium
mkdir -p ~/.claude/skills ~/.codex/skills
ln -s ~/.agents/skills/pr-quiz ~/.claude/skills/pr-quiz
ln -s ~/.agents/skills/pr-quiz ~/.codex/skills/pr-quiz

One checkout, one git pull to update both.

Hosting the page for your phone is optional; see the README.
